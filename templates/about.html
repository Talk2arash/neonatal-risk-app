📖 About This System

Neonatal Risk Prediction using Artificial Neural Networks

🎯 Project Overview

This system was developed as part of a research initiative to leverage Artificial Intelligence and Machine Learning for early detection of neonatal health risks. The goal is to provide healthcare professionals with a reliable decision support tool that can identify high-risk cases based on maternal and clinical factors.

🧠 Model Architecture

The deployed model is a Feedforward Artificial Neural Network (ANN) with the following architecture:

  • Input Layer: 14 features (after feature selection)
  • Hidden Layer 1: 64 neurons (ReLU activation)
  • Hidden Layer 2: 32 neurons (ReLU activation)
  • Output Layer: 2 neurons (Softmax activation)
  • Optimizer: Adam
  • Loss Function: Categorical Crossentropy

🔍 Explainability with SHAP

The system uses SHAP (SHapley Additive exPlanations) to provide interpretable explanations for each prediction. This helps clinicians understand which factors contributed most to the risk assessment, enabling more informed decision-making.

📋 Input Features

The model uses the following 14 features for prediction:

  • Age
  • BMI
  • Education
  • Epilepsy Type
  • Seizure Frequency
  • Duration
  • Medication
  • Dosage
  • Therapy Type
  • Gestational Age
  • Hypertension
  • Diabetes
  • Smoking
  • Alcohol

⚠️ Important Notice

This system is designed for research and practical usage. While it achieves high accuracy, it should be used as a clinical decision support tool and not as a replacement for professional medical judgment. Always consult with qualified healthcare providers for clinical decisions.
